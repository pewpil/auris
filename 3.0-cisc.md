# 3.0 Complex Instruction Set Computer (CISC)

This section covers the **CISC** philosophy, which takes the opposite approach to RISC: provide a rich, complex instruction set where a single instruction can do several low-level operations at once. We examine its principles, advantages, and trade-offs.

CISC was the dominant style in the early days of computing, when memory was expensive and programmers wrote code by hand, so compact, powerful instructions were valuable.

- **3.2** Advantages of the CISC approach.
- **3.3** Trade-offs and modern use cases.
