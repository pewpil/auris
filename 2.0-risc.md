# 2.0 Reduced Instruction Set Computer (RISC)

This section introduces the **RISC** design philosophy: building processors around a small, highly optimized set of simple instructions. We will look at its core principles, the advantages it brings, and where it is used in the real world.

RISC emerged in the 1980s from the observation that most programs used a small subset of instructions most of the time. By simplifying each instruction, designers could build faster, more efficient pipelines.
