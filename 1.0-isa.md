# 1.0 Instruction Set Architecture (ISA)

This is the opening section of our presentation on the Instruction Set Architecture. It introduces what an ISA is, why it matters, and surveys the most common ISAs in use today.

An **Instruction Set Architecture (ISA)** is the abstract model of a computer that is visible to the programmer or compiler writer. It is the line that separates hardware design from software: everything above the ISA is software (compilers, OS, applications), and everything below it is hardware implementation (microarchitecture, circuits).

In this section we will cover:
- **1.1** What the ISA specifies in detail.
- **1.2** Why the ISA matters for portability and hardware evolution.
- **1.3** Examples of common ISAs you will encounter.
