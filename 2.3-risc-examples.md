# 2.3 Examples and Use Cases (RISC)

- **ARM** and **RISC-V** are the leading RISC ISAs.
- Dominant in smartphones, tablets, embedded devices, and growing in laptops and cloud (Apple Silicon, AWS Graviton).

